# كوكب الجحود أكتوبر 🏍️ (October Rider)

لعبة توصيل بالموتوسيكل في 6 أكتوبر. ويب (Three.js) + P2P (PeerJS/WebRTC) + فويس شات + تتغلف لأندرويد بـ Capacitor.

## التشغيل المحلي
```bash
cd october-rider
npm install
npm start            # http://localhost:8080
npm test             # اختبارات المنطق (اللعب، المدينة، المتجر/البنزين/الأوضاع)
```
- لازم نت (بيحمّل Three.js و PeerJS من CDN، وبيسحب خريطة أكتوبر من OpenStreetMap أول مرة وبيخزنها على الجهاز).
- بدون نت للخريطة: بتفتح مدينة بديلة تلقائي.
- المايك محتاج `localhost` أو HTTPS.
- موبايل على نفس الواي فاي: افتح `http://IP-الكمبيوتر:8080` (المايك مش هيشتغل بدون HTTPS — استخدم `npx localtunnel --port 8080` أو انشر الفولدر `www` على Netlify/GitHub Pages).

## نسخة ملف HTML واحد
```bash
npm run build:html     # بيطلّع dist/october-rider.html (638 كيلو، كل حاجة جواه)
```
افتحه بدبل كليك (أو انشره على أي استضافة). لو فتحته من الجهاز مباشرة: الخريطة الحقيقية والغرف والفويس بتحتاج نت، وتبديل الخامات بصور `assets/textures` بيشتغل بس لو اللعبة متشغلة من سيرفر/استضافة (المتصفح بيمنع صور file://). المايك على file:// ممكن يطلب الإذن كل مرة.

## اللعب
- كيبورد: ← → توجيه · ↑ بنزين · ↓ فرامل (وريفيرس) · H كلاكس · M مايك · Tab الترتيب · T رجّعني للشارع
- موبايل: أزرار الشاشة.
- **لوحدك:** زر "العب لوحدك".
- **مع صحابك:** واحد يعمل غرفة (بيطلع كود 5 حروف)، والباقي يكتبوا الكود ويدخلوا. كلهم بيشوفوا بعض لايف، ولوحة الترتيب بتتحدث.
- **فويس:** زر 🎙️ جوه الغرفة. زر 📍 بيبدّل بين صوت بالقرب (بتسمع اللي حواليك بس) وصوت الغرفة كلها.

## الأوضاع (من القائمة)
- 🍔 **توصيل:** طلبات وركّاب (تحت).
- 👮 **لجنة أكتوبر:** بلاغ عن مخالف هربان — الحقه، قرّب منه لحد ما يوقف، وقف جنبه 3 ثواني للفحص. بيدّيك فلوس ونقط، ولو هرب أو الوقت خلص بتخسر المحضر.
- 🏁 **تحدي الطريق:** طريق مفتوح 4 حارات وعربيات من الاتجاهين. قرّب منها بسرعة (نقط + كومبو)، اعمل ويلي (Q أو زر 🏍️↑) للنقط، 3 اصطدامات وتخلص.

## الجراج والمعرض والبنزين
- كل لاعب له **جراج ثابت** على الخريطة (مكانه ثابت من id اللاعب، وصحابك بيشوفوه عندهم بنفس المكان) وبتبدأ قدامه. زر 🏠 بيظهر لما تقرب منه (أو G).
- **المعرض:** سكوتر (مجاني) · موتوسيكل 125 · سبورت 250 · كروزر — بتشتري بالجنيه اللي بتكسبه، وتطوّر المحرك والفرامل والتانك، وتغيّر اللون. الفلوس منفصلة عن النقط.
- **البنزين:** عدّاد في الـ HUD، 18 محطة، سهم GPS لأقرب محطة، وقف جنب الطلمبة وهتتعبّى تلقائي بالجنيه. لو خلص: الونش بيسحبك لأقرب محطة وبتدفع غرامة (حتى 500 جنيه).
- **الأرصفة:** الشوارع الرئيسية ليها رصيف مرتفع بصوبة أبيض/أسود — لو طلعت عليه بتتصد، وبسرعة عالية بتقع. المداخل (قدام الجراج والمحطة) ليها مطلع.
- بانر الطلب والمهمة ليهم زر (—) للتصغير، والمهمة بتصغر لوحدها بعد 6 ثواني.
- **تثبيت على الشاشة الرئيسية:** افتح اللعبة من رابط HTTPS على الموبايل ← "إضافة إلى الشاشة الرئيسية" (فيه manifest وأيقونات وservice worker).

## الميشنز
طلب يظهر كل كام ثانية (مطعم → عميل، أو راكب → وجهة) مع عدّاد. الأكل بيبرد والراكب بيتضايق لو سوقت متهور. تقييم نجوم + بقشيش + سلسلة نجاح (مضاعف نقط). كل 3 توصيلات = مستوى أصعب: مسافات أطول، وقت أضيق، زحمة أكتر.


## ✨ التحديثات الجديدة
**قيادة سهلة:** من القائمة اختار «القيادة»: سهلة (مساعد مسار بيعدّل اتجاهك مع الشارع + اتزان متسامح + البنزين بيخف لوحده في اللفّات الحادة) / متوسطة / عادية. و«البنزين: تلقائي» بيخلّيك تمسك التوجيه والفرامل بس.

**مدينة فيها حياة:** مشاة على الأرصفة (رجالة وستات وأطفال وجلابية، بيمشوا وبيبعدوا لما تقرّب، ولو خبطت واحد بتخسر)، ومرور متنوع (سيدان/هاتشباك/SUV/ربع نقل/تاكسي/ميكروباص/أتوبيس/توك توك/موتوسيكلات). «زحمة المدينة» (منخفضة/متوسطة/عالية) بتتحكم في عدد المشاة والمرور والأشجار حسب قوة جهازك.

**أشجار ولافتات:** فيكس ونخل وشجيرات وورد، لافتات أسماء الشوارع (من OSM)، علامات سرعة وعبور مشاة، يافطات محلات وصيدليات ومطاعم بمظلات وأسماء عربي بتنوّر بالليل، وبيلبوردات وبانرات إعلانية.

**موديلات واقعية:** مركبات مجسّمة بزجاج عاكس وجنوط وفنارات ونمر. وتقدر ترفع موديل GLB حقيقي لأي نوع من لوحة الإدارة.

**التلبيس والرسم:** زر «👕 تلبيس ورسم الشخصية» في القائمة: خوذة (كاملة/نص/كاب)، جسم (جاكيت/هودي/تيشرت/سترة عاكسة)، ألوان الجسم والبنطلون والجزمة والخوذة والبشرة، ولوحة رسم (فرشاة، ممحاة، ختم، نص، تعبئة، تراجع) بترسم على **الجاكيت** و**الخوذة** و**صندوق التوصيل**. اللاعبين التانيين بيشوفوا طقمك في الغرفة.

## 🛠️ لوحة الإدارة (إعلانات وبانرات وربط صور بمعالم)
```bash
npm install
ADMIN_PASSWORD=كلمتك npm run server     # http://localhost:8080  ← اللعبة
                                         # http://localhost:8080/admin/ ← الإدارة
```
(من غير ADMIN_PASSWORD بيولّد كلمة سر ويطبعها أول مرة.)
- **الإعلانات:** ارفع صورة، اختار (بيلبورد / بانر رأسي / لوحة)، حدد مكانها على الخريطة أو سيبها توزيع تلقائي، وتاريخ بداية/نهاية اختياري.
- **المعالم:** اكتب اسم المعلم (أو ابحث عنه)، حدد مكانه، ارفع صورته → بتتلصق على واجهة أقرب مبنى و/أو لوحة قدامه، واسمه بيظهر فوقه.
- **الموديلات:** ارفع GLB لأي نوع مركبة وحدد طوله بالمتر.
- بعد «حفظ ونشر» أي لاعب بيفتح اللعبة من السيرفر بيشوف التغيير. لو اللاعب بيشغّل اللعبة من مكان تاني (ملف HTML أو APK) يكتب عنوان السيرفر في خانة «سيرفر الإعلانات» بالقائمة.
- لازم تستضيف السيرفر على جهاز/استضافة شغّالة (Render / Railway / VPS) واحط `DATA_DIR` على قرص دائم.
- الأمان: كلمة سر مشفّرة، حد محاولات الدخول، رفع png/jpg/webp/glb فقط، وحد 25 ميجا.

- أداء أندرويد الفعلي ما اتقاسش (جرّب «زحمة المدينة: منخفضة» لو الجهاز ضعيف).

- الخرائط الكبيرة، والبانرات الجديدة، والموسيقى على أجهزة حقيقية لسه ما اتقاسوش (اتجربوا على متصفح بدون GPU).

## 💬 رسائل اللعب (تحكم الإدارة)
الرسائل اللي بتظهر تحت بانل الطلبات (التصادم، الوقوع، البنزين، الطلبات، لجنة أكتوبر، الغرفة، الفويس…) بقت كلها في كتالوج واحد `www/js/messages.js`. من **🛠️ لوحة الإدارة ← 💬 الرسائل**:
- تشغيل/إيقاف كل الرسائل، أو أي رسالة لوحدها.
- تعديل نص الرسالة (مع المتغيرات زي `{n}` `{name}`) ونوعها (عادي/أخضر/أحمر) ومدة ظهورها.
- مدة عامة + أقصى عدد رسائل في نفس الوقت + مكان الظهور (تحت بانل الطلبات / أعلى / وسط / أسفل).
- زر 👁 معاينة، وزر ↺ لإرجاع رسالة للافتراضي. «حفظ ونشر» بيطبّقها فورًا (ولكل اللاعبين لو متصل بالسيرفر).
لإضافة رسالة جديدة في الكود: ضيفها في `MSGS` واستدعيها بـ `say('المفتاح', { متغيرات })` في `game.js`.

**اتشال:** السهم الكبير اللي كان تحت بانل الطلبات. سهم بانل الطلب نفسه بقى بيلف بأقصر طريق (من غير لفّة كاملة عند 180°).

## v7 — ملاحظات سريعة
- **صور الإعلانات/المعالم/الخامات**: من لوحة الإدارة، الصورة بتترفع أصلية والقص بالسحب والتكبير (يتحفظ كـ `crop`). تحذير أصفر لو الجودة قليلة بس الحفظ مسموح.
- **خريطة جاهزة**: حط GeoJSON أو Overpass JSON في `www/data/osm.json`.
- **معالم حقيقية**: أضفها من لوحة الإدارة (اسم + موقع + صورة). تأكد من إحداثيات الحصري (فيه تعارض).
- **اختبار**: `npm test` · **بناء**: `npm run build:html`.

## v10 — إضافات
- **المحلات (الشرايح السودا تحت العمارات):** اتصلحت (كانت من غير normals فالإضاءة بتطلعها سودا). وبقى ليها تبويب «🏪 المحلات» في الإدارة: محل لوحده (أقرب محل لموقعك)، شارع كامل، توزيع الإعلانات تلقائي بنسبة، أو إخفاء الكل. زر «🏪 محل هنا» في قايمة الإدارة العائمة.
- **النزول من الموتوسيكل:** زر 🚶 (أو F). تمشي/تجري، وبتركب تاني قرب من الموتوسيكل. حركات: 👋 سلام 💃 رقص 🫡 تحية 👍 تمام 🪑 قعدة 🎉 فرحة (أرقام 1-6). اللاعبين التانيين بيشوفوك.
- **الصوت:** زر 🔊 عائم أثناء اللعب: عام/مؤثرات/موتور/موسيقى/فويس الشات/نطق التحذيرات. 
- **النطق:** التحذيرات والرسائل بتتنطق بصوت عربي (Web Speech). في تبويب «💬 الرسائل»: تشغيل/إيقاف عام، اللهجة، السرعة، النبرة، ولكل رسالة تشغيل النطق ونص نطق مخصص.
- **دليل المعالم:** في تبويب «📍 المعالم» دليل أكتوبر وزايد + إضافة بكود الموقع (Plus Code) أو lat,lon.
- **مجسمات GLB (الإدارة ← 🧍 المجسمات):** السواق النازل، المشاة، اسكوتر اللاعب، موتوسيكل اللاعب. الرفع محتاج السيرفر (حتى 25MB). بعد الحفظ اعمل ريفريش.
- **مشغّل الموسيقى:** الأدمن يرفع أغاني من زر 📤 في المشغّل نفسه أو من تبويب «🎵 الموسيقى»؛ بتشتغل عند كل اللاعبين (محتاج السيرفر). زر 📂 لسه للاعب يشغّل ملفات جهازه.
